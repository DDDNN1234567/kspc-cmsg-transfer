# 竞驰管理通 → 管家婆双版本直导工具 V4.0

一个工具、一个界面，双目标可选：**管家婆财贸双全（cmsg）** 与 **管家婆辉煌 TOP15（top15）**。
源库只有一个：竞驰管理通 `kspcDefault`。所有写库动作均有“导入前备份 + 导入后核验”闭环。

> 本版本把原先两条独立直导链路（V3.0 财贸、TOP15 官方过程适配器）融合为同一套 GUI、同一套字典、同一套校验记录；并用真实库写入后的逐字段交叉验证确认字典准确。

## 一、双目标能力

| 能力 | 财贸双全 | 辉煌 TOP15 |
|---|---|---|
| 往来单位（含父子/兼客户） | ✅ `Btype` | ✅ `btype`，官方过程续排树编号 |
| 商品（含分类/双单位） | ✅ `ptype + T_Jxc_PtypeUnit` | ✅ `ptype + xw_PtypeUnit` |

| 扩展价格 | 预设价 1–5、会员/特价按目标列写 | `0119–0122` 自定义价格类型 |
| 扩展辅助单位 | `nUnit=1..4` 矩阵 | 第 3/4 单位 + 换算率 |
| MDF / LDF 直接附加 | ✅ 两侧都可选 | ✅ 两侧都可选 |
| 官方过程 | 目标自带 `xw_GetBasicData` 读取链 | 7 个 `p_hh_*` 写入过程 + 读取链 |
| 导入前备份 | ✅ 默认整库 `.bak` | ✅ 默认整库 `.bak` |
| 校验 | 32 项常规 + 225 项逐字段 | 14 项常规 + 119 项逐字段（含部门 5 项） |

## 二、MDF / LDF 直接选取

连接页左右两侧各有“浏览 MDF”“浏览 LDF”“附加并选中”：

- 选择 `.mdf` 后自动探测同名日志：`<库>_log.ldf` 与 `<库>.ldf` 两种命名都支持；
- 未找到 LDF 时走 `ATTACH_REBUILD_LOG` 重建日志；
- 已经附加在当前实例上的文件，直接返回现有库名并选中，不重复 `ATTACH`；
- 离线库自动 `SET ONLINE`；
- 源/目标可分别附加，互不影响。

## 三、真实数据实测结果

### 3.1 财贸双全（目标 `财贸测试demo`）

- 32 项常规校验：**32/32 通过**
- 225 项逐字段严格核对：**225/225 通过，0 不符**
- 官方读取链路 B/P/K/E/D/A 六模式全部通过；B 7 行（6 条导入）、P 3 行（2 条）、K 7 行（4 条）、E 4 行（1 条）、D 3 行（1 条）、A 135 行（0 条，按设计）
- 库存读取：期初 100 / 当前结存 90，各按各口径核对
- 商品简称：源 `name` 为空，已回退全名；客户端读取 `pname` 显示 `测试商品 / 测试123`

### 3.2 辉煌 TOP15（隔离副本 `HH15testV4`，由 `HH15new` COPY_ONLY 备份还原）

- 10 模块全量导入：`unit=5 warehouse=4 employee=1 department=1 goods=2 stockini=1 barcode=1 fail=0`
- 14 项常规校验：**14/14 通过**
- **119 项逐字段交叉验证：119/119 通过，0 不符**
  - 往来单位 70/70、商品 16/16、仓库 16/16、职员 7/7、部门 5/5、期初 3/3、条码 2/2
- 实测落库：`btype 00023/00024/0002400001/00025/00026`、`ptype 00089/0008900001`、`Stock 00024–00027`、`employee 00010`、`department 00001 业务部`、期初 1 行、条码 1 条、`xw_PtypeUnit` 3 行（含 `件 / URate=100`）
- 官方读取：B 898 行（5 条导入）、P **24,738 行**（2 条）、K 24 行（4 条）、E 8 行（1 条）、D 3 行（1 条）、A 73 行（0 条，按设计）
- 读取参数必须 `EXEC dbo.xw_GetBasicData ?,0,'',0,0`；起止写成 `1,200000` 会把商品/部门退化成 1 行。

> 辉煌侧用隔离副本而不是直接写 `HH15new`，是为了保证可重复、可回滚；副本由真实 `HH15new` 的 `COPY_ONLY` 备份还原，结构与真实账套一致。

## 五、运行

```powershell
$env:KSPC_PWD = '<本机 sa 密码>'
python kpsc_unified_gui.py
```

或直接运行 `竞驰转管家婆双版本工具V4.0.exe`。密码只从环境变量读取；交付文件、日志、字典、GitHub 均不含明文密码。

### 典型流程

1. 源侧：填实例/库，或选 `kspcDefault.mdf` → 附加并选中 → 测试连接。
2. 目标侧：选择“财贸双全”或“辉煌 TOP15” → 填实例/库，或选目标 MDF → 附加并选中。
3. 预检：确认源表、目标必需表/官方过程齐全。
4. 备份：默认勾选“导入前整库备份”，备份路径必须在 SQL Server 服务账户可写目录。
5. 一键直导 → 自动核验 → 查看汇总与逐项结果 → 清缓存提示。
6. 字典页可重新生成双版本字典；结果页可导出本次校验记录。

## 七、边界

- 登录用户/权限/会话/日志/单据/自定义报表等按设计不迁移，原因见字典“未迁移”列。
- `t_base_kmb` 会计科目 50 行未迁移；目标账套自有科目体系。
- 源 `t_base_price` 为 0 行，客户价格追踪按“无数据不写”处理。
- 辉煌官方过程会改写自定义编号；明细表引用一律使用过程 `OUTPUT` 的真实树编号（`g_tree/u_tree`），不能用源编号映射。
- 目标已有同编号/同名称时，官方过程报 `rc=-1124`；工具会做编号与名称双唯一化，并在名称后加 `(竞驰)` 便于溯源。
