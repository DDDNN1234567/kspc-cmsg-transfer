# 功能日志 V4.0

## 版本定位

V4.0 = V3.0 财贸单目标 + 辉煌 TOP15 官方过程适配器 → **一个工具、一个界面、双目标可选**。
所有历史修复（见下方排除清单）全部保留，不重新实现旧缺陷。

## 2026-11-06 本段改动

### 1. 双目标融合

- 新增统一 GUI `kpsc_unified_gui.py`：目标卡片、双目标共用源连接、目标库/徽标/提示/备份目录联动。
- 统一结果表：财贸 32 项、辉煌 14 项均以 `(项目, 结果, 说明)` 展示。
- 新增“预检、附加、备份、字典、修复、清缓存”同一界面入口。
- 删除 `cn if False else ...` 硬编码残留，`test_conn` top15 分支改为显式源连接 + `try/finally` 关闭。

### 2. MDF / LDF 附加

- `attach_database_file()` 自动探测两种日志命名：`<库>_log.ldf`、`<库>.ldf`。
- GUI `choose_mdf()` 同步双候选；状态文案区分“已选 MDF + LDF”与“仅 MDF，将重建日志”。
- 实测：
  - `kspcDefault.mdf` + `SQLEXPRESS` → `existing / ONLINE`
  - `HH15new.mdf` + `SQLSERVER` → `existing / ONLINE`
  - `财贸测试demo.mdf` + `SQLSERVER` → `existing / ONLINE`（本轮修好 `.ldf` 无 `_log` 后缀）

### 3. 辉煌字段级交叉验证

- 新增 `v4_top15_dict_verify.py`：按目标备注 `竞驰ID:n` 反查源行，逐字段回读。
- 修复三处真缺陷：
  1. `call_unit` 补 `bank=`（`@Bank` 与 `@BankAccounts` 是两参），银行账号不再空；
  2. 职员插入后 `UPDATE employee SET ename=?`（官方过程无 `@name`）；
  3. 辅助单位换算率优先 `unitrelation2`（“件”`URate=100`，不是 1）。
- 结果：**114/114 通过**（往来 70、商品 16、仓库 16、职员 7、期初 3、条码 2）。

### 4. 财贸复核

- 结果：常规 **32/32**、严格 **225/225**、`bad=0`。
