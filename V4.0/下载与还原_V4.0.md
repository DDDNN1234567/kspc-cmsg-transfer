## 二、桌面还原

```powershell
$zip = "C:\Users\<用户>\Desktop\竞驰转管家婆双版本工具V4.0\源码包_V4.0.zip"
(Get-FileHash $zip -Algorithm SHA256).Hash
Expand-Archive $zip -DestinationPath ".\源码" -Force
```

SHA256 应为 `328E4D7DFDD6720D05EC73D5870622693A445C68B41024C1C1837FB38A67C813`。

`还原源码_V4.0.ps1` 用于仓库分片场景：它要求 `V4.0/` 下存在 **14 片**（前 13 片各 8,000 字符、末片 7,256 字符，合计 111,256 字符），缺片会直接报错退出，不会产出半成品。

## 四、说明

- 分片必须是**连续、无额外换行**的 8,000 字符块；拼接时多一个换行，SHA256 就会变。
- 桌面交付目录已含解码后的全部文件与 exe，普通用户不需要执行还原。
- exe 未上传：GitHub 文本接口不能传二进制，且仓库未启用 Git LFS；exe 仅随桌面包交付。
- 若只需要运行，直接用桌面的 `竞驰转管家婆双版本工具V4.0.exe`；源码包用于审计与二次开发。
