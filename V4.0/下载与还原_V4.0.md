# V4.0 下载与还原说明

仓库同时保存“可直接阅读的文档”与“源码包分片”。GitHub 文本接口对二进制和超长文本会截断，所以源码不逐个 `.py` 上传，而是打成 zip、base64 后按 **8,000 字符 / 片**保存。

## 一、源码包

| 项 | 值 |
|---|---|
| 合并后文件 | `源码包_V4.0.zip` |
| 大小 | 79,781 B |
| SHA256 | `85C4EC1AA95387D89CF131D496BD48D5C946B221FDDFBF808C041B0471E93E7A` |
| 分片 | `源码包_V4.0.zip.b64.part01` – `part14`（前 13 片各 8,000 字符，末片 2,376 字符） |
| 内容 | 7 个运行文件：GUI、财贸引擎、财贸字典、双版本字典、辉煌适配器、辉煌过程封装、辉煌编排 |

PowerShell 还原：

```powershell
$dir = "V4.0"
$parts = Get-ChildItem $dir -Filter "源码包_V4.0.zip.b64.part*" | Sort-Object Name
if ($parts.Count -ne 14) { throw "分片数量不是 14：$($parts.Count)" }
$s = ($parts | ForEach-Object { Get-Content -LiteralPath $_.FullName -Raw }) -join ""
if ($s.Length -ne 106376) { throw "合并长度不是 106376：$($s.Length)" }
[IO.File]::WriteAllText("$dir\源码包_V4.0.zip.b64", $s, (New-Object Text.UTF8Encoding($false)))
certutil -decode "$dir\源码包_V4.0.zip.b64" "$dir\源码包_V4.0.zip"
(Get-FileHash "$dir\源码包_V4.0.zip" -Algorithm SHA256).Hash
Expand-Archive "$dir\源码包_V4.0.zip" -DestinationPath "$dir\源码" -Force
```

SHA256 应为 `85C4EC1AA95387D89CF131D496BD48D5C946B221FDDFBF808C041B0471E93E7A`。

## 二、文档

`V4.0\` 与 `V4.0\文档\` 下的 `.md`、`.csv`、`.json`、`.png` 可直接查看，不需要解码。重点：

- `README.md`：总览；
- `项目说明_V4.0.md`：架构、功能、运行、边界；
- `项目设计经验总结_V4.0.md`：工程经验与避坑；

- `文档\数据字典_竞驰到双版本_V4.0.csv`：字段级字典。

## 三、快捷还原脚本

仓库根目录有 `还原源码_V4.0.ps1`，在仓库根执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\还原源码_V4.0.ps1
```

脚本会校验分片数量、合并长度、zip SHA256，再解压到 `V4.0\源码`。

## 四、说明

- 分片必须是**连续、无额外换行**的 8,000 字符块；拼接时多一个换行，SHA256 就会变。
- 桌面交付目录已含解码后的全部文件与 exe，普通用户不需要执行还原。
- exe 未上传：GitHub 文本接口不能传二进制，且仓库未启用 Git LFS；exe 仅随桌面包交付。
- 若只需要运行，直接用桌面的 `竞驰转管家婆双版本工具V4.0.exe`；源码包用于审计与二次开发。
