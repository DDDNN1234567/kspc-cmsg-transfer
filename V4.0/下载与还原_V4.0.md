# V4.0 下载与还原说明

仓库里的 `.py` 与 `.md` 可直接查看；两个大包以 base64 分片保存，避免 GitHub 文本接口对二进制/大文件截断。

## 一、源码包

| 项 | 值 |
|---|---|
| 合并后文件 | `源码包_V4.0.zip` |
| 大小 | 79,699 B |
| SHA256 | `970EF92B26776FE2FBB6AAF980EA562FA54F46AE0958BD960026045F43356C69` |
| 分片 | `源码包_V4.0.zip.b64.part01` – `part04` |

PowerShell 还原：

```powershell
$dir = "V4.0"
$s = (Get-ChildItem $dir -Filter "源码包_V4.0.zip.b64.part*" | Sort-Object Name |
      ForEach-Object { Get-Content -LiteralPath $_.FullName -Raw }) -join ""
[IO.File]::WriteAllText("$dir/源码包_V4.0.zip.b64", $s, (New-Object Text.UTF8Encoding($false)))
certutil -decode "$dir/源码包_V4.0.zip.b64" "$dir/源码包_V4.0.zip"
(Get-FileHash "$dir/源码包_V4.0.zip" -Algorithm SHA256).Hash
Expand-Archive "$dir/源码包_V4.0.zip" -DestinationPath "$dir/源码" -Force
```

## 三、说明

- 两个包的 SHA256 必须与上表一致；不一致说明分片缺失或拼接时混入换行。
- 桌面交付目录已含解码后的全部文件与 exe，普通用户不需要执行上面的还原步骤。
- exe 未上传：GitHub 文本接口不能传二进制，且当前仓库未启用 Git LFS；exe 仅随桌面包交付。
