# 使用说明 V4.0 完成版

## 1. 启动

- 免安装：双击 `竞驰转管家婆双版本工具V4.0.exe`。
- 源码：`python kpsc_unified_gui.py`。
- 连接参数全部不预设，服务器/实例、用户名、密码、账套库均在界面手工输入；密码只存在于当前输入框，不写进任何配置文件，也不进日志/文档/GitHub。

## 2. 界面结构

| 页签 | 用途 |
|---|---|
| 1. 连接与目标 | 选财贸/辉煌；源/目标连接；MDF/LDF 附加；只读预检 |
| 2. 一键直导 | 执行选项、备份、模块勾选、一键导入、结果汇总 |
| 3. 校验与修复 | 单独跑常规校验、重算子级、归位 UpdateTag、清缓存 |
| 4. 双版本字典 | 生成字典 CSV/MD/核心映射/元数据 |
| 运行日志 | 全程日志，可复制/导出/清空 |

### 2.1 选目标

- 点“管家婆财贸双全”或“管家婆辉煌 TOP15”卡片；
- 徽标、当前目标提示、校验口径会同步切换；
- **连接参数不预设**：服务器/实例、用户名、密码、账套库由用户手工输入；点“刷新库”拉取在线库列表后，从下拉框选择；
- 切换目标**不会覆盖**已填写的服务器、用户名、密码或库名；
- 两目标共用同一套源连接，不需要重启。

### 2.2 选择 MDF / LDF

1. 点“浏览…”选 `.mdf`；
2. 工具自动找同名日志：先试 `<库>_log.ldf`，再试 `<库>.ldf`；
3. 找到就自动填入 LDF；找不到就留空，附加时 `ATTACH_REBUILD_LOG` 重建；
4. 点“附加选中”：已附加则直接选中现有库；离线库自动 `ONLINE`；未附加则 `ATTACH`；
5. 源和目标可分别操作。

> 同一 MDF 已被另一个 SQL Server 实例附加时，再附加会报“另一个程序正在使用此文件（错误 32）”；换回原实例即可。跨服务账户访问别人的目录会报错误 5，请把文件放到目标实例服务账户可读的目录。

### 2.3 只读预检

检查源表行数、目标必需表、辉煌官方过程、账套开账状态；**不写数据**。建议每次先跑。

## 3. 一键直导

1. 确认目标页签与目标库；
2. 勾选“导入前备份目标账套”（默认开）；
3. 财贸可勾选结存库存、客户价格追踪、兼容价格；辉煌可勾选 10 个模块（含部门）；
4. 点“开始一键直导”；
5. 完成后看“结果汇总”和“逐项校验”；
6. 按提示清客户端缓存并重登软件。

### 财贸顺序

往来单位 → 商品 → 仓库 → 职员 → 部门 → 期初 → 结存 → 单位价格 → 价格追踪 → 条码 → 归位标记。

### 辉煌顺序

往来单位 → 仓库 → 职员 → 部门（官方树）→ 商品（含分类/双单位）→ 期初 → 客户价格 → 条码 → 扩展价格 → 扩展辅助单位 → 14 项校验。

## 4. 校验与修复

- “重新校验”：不改数据，只跑 32 项（财贸）或 14 项（辉煌）；
- 逐字段核对：财贸 **247 项**、辉煌 **133 项**（含部门 5 项）；
- 官方模板核对：读取 `F:\GraspServer\CMSQ\BackUp\存货档案.xls`，对 27 列 + 6 项关联逐项比对，当前 **33/33 通过**；
- 官方读取验收：调用目标自带 `xw_GetBasicData` 的 `B/P/K/E/D/A` 六模式，确认导入行在客户端读取结果中可见；
- “重算子级”：按父子关系重算 `soncount/psonnum/bsonnum/esonnum`；
- “归位标记”：`updatetag=10000` + `xw_BaseUpdateTag=0`；
- “清缓存”：只清理当前账套的客户端缓存，重登生效；不会删除其他账套缓存。

## 5. 双版本字典

- 输出目录默认 `文档\`；
- 生成 5 件：双版本 CSV、MD、核心映射 CSV、元数据 JSON、生成日志；
- CSV 每行带“目标版本”，可直接筛财贸/辉煌；
- `目标缺列` 必须为 0 才视为字典可用。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 连接失败 IM002 | 装 `ODBC Driver 17 for SQL Server`；工具会自动选驱动 |
| 附加报错误 32 | 该 MDF 已被另一实例占用，换回原实例 |
| 附加报错误 5 | 目标实例服务账户无权读该目录，换目录或授权 |
| 辉煌 `rc=-1124` | 编号或名称重复；工具已做双唯一化，仍报请查目标已有同名 |
| 商品列表整块报 245 | 条码 `UnitID` 不是数字串；工具统一写 `'0'` |
| 导入后软件看不到 | 先清缓存重登；再查 `updatetag`、`deleted`、编号级联、子级计数 |
| 商品简称/名称为空 | 源 `name` 可能为空；V4.0 已自动回退 `fullname`，重跑该商品模块即可 |
| 辉煌部门多出一条 `业务部(竞驰)` | 早期无幂等版本重复导入；V4.0 已按 `dcomment=竞驰ID:n` 跳过，历史重复行需人工清理 |
| 期初写入失败 | 辉煌需 `sysdata.iniover=0`；工具自动临时关闭并恢复 |

## 7. 安全边界

- 默认不在真实账套上做“清空重导”；
- 每次导入前整库备份，备份路径由用户指定；
- 测试请用隔离副本（如 `HH15testV4`），确认后再切真实库；
- 交付文件不含明文密码。
