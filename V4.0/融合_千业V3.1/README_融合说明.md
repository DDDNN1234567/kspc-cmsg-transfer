## 四、为什么先做包级融合

1. 千业与竞驰的源表、编号模型、库存口径不同，直接塞进 V4.0 同一“源库卡片”会把两套连接和预检逻辑混在一起，回归风险高。
2. V4.0 是已完成版交付，GUI/EXE 有固定哈希；为融合而改主程序会让 247/133/33 的复验结果失效。
3. 千业 v3.1 的 EXE 已经独立可用，先保证“一个交付项目内两个入口都可运行”，再做同窗适配器。
