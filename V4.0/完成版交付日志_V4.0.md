## 四、目录勘探关键发现

- 财贸 `BaseInfo\<账套>\<GUID>` 是 SQLite 基本资料缓存；`财贸测试demo` 当前缓存 `B=7 / P=3 / K=7 / E=4 / D=3`，而库内 `Btype=8`（含 `00006 测试单位`）。缓存是导入前快照，客户端需清缓存重开账套才显示新单位。
- 辉煌 `localData\HH15new-00000-*` 是 GBK 文本缓存，首行库名、次行 GUID、末行 `$$BaseInfoEnd$$`；清理必须按账套前缀，不能误删其他账套。
- 竞驰 `D:\kspcV81\BZ\client\XDevCore.ini` 只有设备型号，无数据库连接串；`kspcCore.dll` 仅 267 B，安装残缺。迁移仍只读 `_inner` 表，连接参数必须用户输入。
- `IndustryTradeSystem`、`RPDB.db`、`TABLE_*.cds`、`Graspcfg.dat` 只做格式识别，未作为迁移数据源。
