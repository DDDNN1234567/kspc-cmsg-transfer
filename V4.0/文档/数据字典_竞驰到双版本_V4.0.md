## 五、两版本结构性差异（真实库实查）

| 项目 | 财贸双全 | 辉煌 TOP15 |
|---|---|---|
| 商品基本单位 | `T_Jxc_PtypeUnit` 多行价格/单位矩阵 | `ptype.punitname` + `xw_PtypeUnit` |
| 仓库层级 | 保留父子 `Stock` | 必须平铺，类仓库不能挂库存 |
| 单位价格 | `T_Jxc_PtypeUnit` + `xw_P_PriceFollow` | `xw_P_PtypePrice` + `xw_P_PriceFollow` |
| 期初库存过程 | 直写 `IniGoodsStocks` | 官方 `p_hh_ModInitGoodsStocks_SNMng_Package` |
| 客户价格追踪 | `xw_P_PriceFollow` 四组 | `p_hh_ImportPtypePriceGZ` 四组 |
| 扩展价格 | 兼容价格表可写 | 需先建 0119-0122 自定义价格类型 |
| 编号规则 | 数字+级联，允许目标续排 | 官方过程按库内现状续排，父引用必须用 OUTPUT |
| 客户端读取 | `xw_GetBasicData` B/C/V/P/K/E/D | 同过程，但参数形态不同 |

## 六、未迁移字段处理

所有未迁移字段仍在 CSV 中逐条列出，状态为“未迁移”，并在转换规则列写明原因，
不静默丢弃。会计科目、权限、系统参数、登录用户、单据流水按目标软件自有体系保留。

## 七、复核方法

1. 比对键：`(目标版本, 源表.lower(), 源字段.lower())`。
2. 每条已映射行重新查目标 `sys.columns`，确认目标表/列存在。
3. 目标类型为空只允许两种原因：目标缺列，或字段由官方过程动态生成。
4. 数据层再用两版本各自的校验项复核行数、父子引用、数量金额。
