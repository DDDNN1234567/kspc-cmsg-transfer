## 四、本轮修复后新增的实测结论

| 问题 | 现象 | 根因 | 修法 / 实测 |
|---|---|---|---|
| 辅助单位换算率错 | 目标“件”`URate=1`，源 `unitrelation2=100` | 适配器取了 `unitrelation`（基本比例 1），不是 `unitrelation2` | 改为优先 `unitrelation2`；重导后 `件 URate=100` |
| 职员简称为空 | `employee.ename=''` | 官方 `p_hh_BasicInsertE_Commodity` 没有 `@name` 参数 | 成功插入后按源 `name` 执行 `UPDATE employee SET ename=? WHERE etypeid=?` |
| 子客户银行账号空 | 源 `109 bankcount=1111111`，目标空 | `call_unit` 只传 `bankacct`，未传 `bank` | 两个参数同传源值；重导后通过 |
| LDF 自动探测漏 | 财贸实际日志名 `财贸测试demo.ldf`，非 `_log.ldf` | 只探测 `<stem>_log.ldf` | 增加 `<stem>.ldf` 候选；三套真实库附加实测 3/3 命中 |
| GUI 启动崩溃 | `grid inside pack` | `_card` 把标题标签 `pack` 进 body，字段又 `grid` 进同一 body | 标题拆到独立 head 帧；GUI 冒烟通过 |
| GUI 启动崩溃 | `KeyError: target_hint` | `_defaults` 漏初始化 `target_hint` | 补默认值；目标切换 cmsg↔top15 冒烟通过 |
