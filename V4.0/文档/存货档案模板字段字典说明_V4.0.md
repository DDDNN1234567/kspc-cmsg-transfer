# 存货档案模板字段字典说明（V4.0 最终验证版）

> 依据官方模板：`F:/GraspServer/CMSQ/BackUp/存货档案.xls`（1 个 sheet、27 列、1 条样例）。
> 目标库：`财贸测试demo` 的 `ptype` 及关联单位/条码表。
> 配套机器可读字典：`V4.0/文档/存货档案模板字段字典_V4.0.csv`。
> 口径：模板列名、列序、字段语义为基准；模板样例值与源库、财贸官方导入过程冲突时，按字段语义判定并标注。

## 一、表关系

| 层级 | 表 | 本模板涉及内容 | 说明 |
|---|---|---|---|
| 主表 | `ptype` | 编号、名称、单位、价格、成本计价、备注 | 商品主档，模板 27 列中的大部分落在此表 |
| 单位矩阵 | `T_Jxc_PtypeUnit` | 基本单位、辅助单位1、换算率、条码 | `nUnit=1/2`，界面与库存换算依赖此表 |
| 单位展示 | `xw_PtypeUnit` | 基本单位、IsBase、URate | 财贸官方读取/界面展示用 |
| 条码 | `xw_PtypeBarCode` | 条码、UnitID | 独立条码表，`UnitID` 必须是数字串 |
| 父记录 | `ptype.ParRec` | 父记录指针 | 模板未列，但官方新增导入过程维护 |

## 二、27 列分组

- **编号与名称（1-5）**：`ParId/typeId/FullName/Name/Namepy`；编号按父子级联生成，简名源空时回退全名。
- **属性（6-9）**：`Standard/Type/Area/barcode`；条码同时写 `ptype`、`T_Jxc_PtypeUnit`、`xw_PtypeBarCode`。
- **单位（10-12）**：`Unit1/Unit2/UnitRate1`；`UnitRate1` 是辅助单位1 的换算率，源字段取 `unitrelation2`。
- **默认单位（13-14）**：`DefInUnit/DefOutUnit` 存单位序号，`1` 表示基本单位；模板按单位名显示。
- **价格（15-21）**：`recPrice/MinSalePrice/preprice1..5`；模板空值与目标 `0.0000` 按空/0 互认。
- **备注与成本（22-27）**：`Comment/costmode/bBlockNo/TakeOut/PObject/CostPrice`；备注含 `竞驰导入|原编号|原ID|规格组` 标记，用于幂等和溯源。

## 三、关键口径（容易错的三处）

1. **单位关系1**：财贸 `ptype.UnitRate1` 对应 `Unit2`（辅助单位1），不是基本单位自身关系；源 `unitrelation` 恒为 1，不能写入。最终商品 `0000100001` 为 `UnitRate1=100`、`UnitRate2=1`，`T_Jxc_PtypeUnit nUnit=2` 为 `件/100`。模板样例 `1` 是旧版错误映射回显。
2. **默认单位**：模板显示“个”，目标存 `1`；`1` 是单位序号，不是数量。
3. **父记录**：`ParRec` 必须等于父行 `Rec`；五表（ptype/Btype/Stock/Employee/Department）同规则。模板未列，但官方 `P_BAS_ImportPtype` 在新增导入后专门回填。

## 四、最终实测值

| 检查 | 结果 |
|---|---|
| 模板 27 列 | 26 列一致；`单位关系1` 模板 1 / 最终 100（按字段语义修正） |
| 关联 6 项 | 全部一致 |
| `T_Jxc_PtypeUnit` | 3 行：`00001/nUnit1/个/1`；`0000100001/nUnit1/个/1/条码`；`0000100001/nUnit2/件/100` |
| `xw_PtypeUnit` | 2 行，基本单位 `个/1/IsBase=1` |
| `xw_PtypeBarCode` | 1 行，`UnitID='0'/1234123123124` |
| 官方 `P` 读取 | 3 行；商品 `UnitRate1=100`、`UnitRate2=1`、`unit2=件` |
| 五表 `ParRec` | 16 个非根行全部等于父行 `Rec`，`bad 0` |
| 结存成本期间 | `202611` |

## 五、模板未列字段

模板仅 27 列，`ptype` 实际 116 列。以下字段在财贸导入模板字符串中存在但本模板未列，本轮不写入、不补默认值：

`辅助单位2/单位关系2`、`默认供应商/默认仓库/默认品牌/默认车间`、`六级~十五级批发价`、`保质期`、`是否外购/自制/委外`、`自定义项1~4`、`存货税率`、`安全库存数量/天数`、`采购/生产/委外周期`、`启用序列号管理`、`是否倒冲领料`、`存货备用`。

其中源商品 `bzDateNum=150`（保质期天数）当前未写入 `ptype.ShelfLife`（0），因不在本模板 27 列内；后续按完整导入模板复核时应单独纳入。

## 六、待确认项（补强建议）

1. 模板“四级/五级批发价”与 `preprice4/preprice5` 的列位：V4 当前把源 `price` 写 `preprice4`、源 `price4` 写 `preprice5`，源 `price5` 额外写 `preprice6`；实测值均为 0。建议在完整模板复核时按官方列义收敛为 `preprice1..5`。
2. 源 `serialType` 当前未显式写入 `bBlockNo`；模板样例为“否”，目标默认 0，值一致，但完整模板复核时应确认管理批号语义。
3. 源 `bzDateNum` 当前未写入 `ShelfLife`；模板未列，属模板外字段。
4. `MinSalePrice/CostPrice` 已补映射；当前样例值 0，若后续有非零源值应重跑并核对 `T_Jxc_PtypeUnit.MinSalePrice`。
