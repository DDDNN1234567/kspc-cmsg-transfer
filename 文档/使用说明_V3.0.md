# 竞驰转财贸直导工具 V3.0 使用说明

版本：V3.0（2026-11-06 修订）
适用：竞驰管理通账套库 → 管家婆财贸双全账套库

## 一、适用范围

本工具把 **竞驰管理通** 账套库中的基础资料、库存与价格数据，按字段对应关系直导到 **管家婆财贸双全** 账套，并给出可复核的字典与核对结果。

覆盖对象：

- 基本信息：往来单位、存货商品、仓库、职员、部门
- 库存：期初库存、结存库存（数量 / 成本）
- 价格：商品单位价格、客户价格追踪、最近价格
- 账套文件：直接选择 `.mdf` / `.ldf` 附加到 SQL Server 实例，并自动选中账套库
- 字典与核对：源/目标全字段字典、逐字段严格核对、工作目录核对、软件完整性检查

不覆盖：单据流水、会计凭证、权限配置、登录用户、程序配置、自定义报表。源库这些表要么无数据，要么属于目标软件自有体系，工具会在字典中逐表标注原因。

## 二、运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 x64 |
| 源数据库 | SQL Server 2008 Express，实例 `DESKTOP-8P5G8VQ\SQLEXPRESS` |
| 目标数据库 | SQL Server 2016，实例 `DESKTOP-8P5G8VQ\SQLSERVER` |
| ODBC 驱动 | `ODBC Driver 17 for SQL Server`（工具自动探测，无需手工配置） |
| 源库文件 | `D:\kspcV81\BZ\server\workData\kspcDefault.mdf` |
| 目标库文件 | `F:\GraspServer\CMSQ\Data\财贸测试demo.mdf` |

注意：

- 必须写 **命名实例**。`localhost`、`.`、`(local)` 在本机没有默认实例，连不上。
- 两个库分属两个实例，不能同库 `INSERT ... SELECT`，工具用双连接逐行字段映射写入。
- 目标库名是中文 `财贸测试demo`，连接串按原样传递。
- 驱动连接串包含 `TrustServerCertificate=yes`，避免 SQL Server 2016 证书校验失败。
- 选择 MDF/LDF 附加时，SQL Server **服务账户**必须能读写这两个文件；文件在服务账户无权访问的目录时，附加会报“操作系统错误 5（拒绝访问）”。

## 三、首次使用

### 1. 备份

一键直导前建议勾选“导入前备份目标库”。工具会调用 SQL Server 备份到指定 `.bak` 路径。

已有可回滚备份：

- `F:\GraspServer\CMSQ\BackUp\财贸测试demo_迁移前_20261106.bak`（迁移前最干净）
- `F:\GraspServer\CMSQ\BackUp\竞驰直导前_20261106.bak`
- `F:\GraspServer\CMSQ\BackUp\竞驰直导前_结存补写_20261106.bak`
- `F:\GraspServer\CMSQ\BackUp\竞驰直导前_终版_20261106.bak`

回滚前先查看备份头（不要在末尾加 `WITH NO_INFOMSGS`）：

```sql
RESTORE HEADERONLY FROM DISK = N'F:\GraspServer\CMSQ\BackUp\财贸测试demo_迁移前_20261106.bak'
```

### 2. 启动

双击 `竞驰转财贸直导工具V3.0.exe`。

也可以源码运行：

```powershell
cd C:\Users\MEE\Desktop\竞驰转财贸直导工具V3.0
python kpsc_gui.py
```

源码运行需要 Python 3 和 `pyodbc`。

### 3. 连接方式一：直接选在线库

“1. 连接 / 账套文件”页两侧各填写：

- 源库：服务器 `DESKTOP-8P5G8VQ\SQLEXPRESS`，用户名 `sa`，密码按实际填写。
- 目标库：服务器 `DESKTOP-8P5G8VQ\SQLSERVER`，用户名 `sa`，密码按实际填写。
- 点“刷新库列表”拉取实例上的在线库；源侧优先选含 `kspc` 的库，目标侧优先选含“财贸”或 `CMSQ` 的库。
- 点两侧“测试连接”，日志出现“连接成功，当前库 …”即可。

### 4. 连接方式二：直接选 MDF / LDF 文件

这是 V3.0 新增入口，适合账套尚未附加、或不确定账套库名的场景。

1. 在源库或目标库分组里点 **MDF 文件** 行的“浏览…”，选择 `.mdf`。
2. 选择后工具自动探测同目录、同名的 `.ldf`：
   - 找到：状态显示“已选择 MDF + 同名 LDF”。
   - 没找到：状态显示“已选择 MDF；未找到同名 LDF，将重建日志”。
3. 需要换日志文件时，点 **LDF 文件** 行的“浏览…”单独选择；LDF 可以留空。
4. 点该侧的“附加并选中库”，或点页面中部的 **“附加两侧文件”** 一次处理两侧。
5. 成功后：
   - 数据库下拉框自动填入并选中附加后的库名；
   - 状态显示“已附加并选中：库名”或“已识别并选中：库名”；
   - 运行日志显示状态 `ONLINE`、动作 `attached` / `existing`。

工具的处理规则：

| 场景 | 行为 |
|---|---|
| MDF 已在当前实例附加 | 按物理路径识别，直接选中现有库，不重复附加 |
| 已附加但处于 OFFLINE | 执行 `ALTER DATABASE … SET ONLINE` 后选中 |
| 未附加，MDF + LDF 都在 | `CREATE DATABASE … FOR ATTACH` |
| 未附加，只有 MDF | `CREATE DATABASE … FOR ATTACH_REBUILD_LOG`，由 SQL Server 重建日志 |
| 实例上已有同名库但物理文件不同 | 中止并提示改名或换 MDF，避免误连到别的账套 |

附加只负责“把账套挂到实例并选中库”，不会自动写入数据；确认库名后，仍按第四节点“一键直导”。

常见附加报错：

- `操作系统错误 5（拒绝访问）`：SQL Server 服务账户无权读写文件。把 MDF/LDF 放到服务账户可访问的目录，或先在 SSMS 中附加。
- `MDF/LDF 不配套` / 文件被占用：确认 LDF 属于同一账套，且没有被其他实例或进程占用。
- 同名库冲突：工具不会覆盖已有库，请先改名或选择正确的 MDF。

### 5. 预检

点“只读预检两侧账套结构”。工具检查：

- 源库 10 张对象表是否存在、各有多少行
- 目标库 11 张关键表是否存在
- 目标账套当前期间
- 源/目标行数概览

预检通过后再继续。若提示缺表，先确认连的是正确账套库，不要强行导入。

### 6. 编号预览

点“预览编号与映射”。工具显示源编号到目标编号的对应关系，包括父级、子级、备注中的原编号。

确认层级和编号段符合预期后再执行直导。编号规则：

- 纯数字，长度 ≥5 且为 5 的倍数
- 一级 `00001` 起
- 子级 = 父编号 + 5 位行序，例如 `0000100001`
- 原编号写入备注 `原编号:xxx`

## 四、一键直导

“2. 一键直导”页勾选：

- **结存库存**：默认勾选。写 `GoodsStocks` 与 `GoodsStockscost`，期间取账套当前期间。
- **客户价格追踪**：默认勾选。写 `xw_P_PriceFollow` 与 `RecPrice`。
- **导入前备份目标库**：建议勾选。
- **导入后清客户端缓存**：按需勾选；工具会尝试清理财贸客户端 `BaseInfo` 缓存。
- **另建“兼客户”单位**：默认不勾。竞驰的“加盟代理:客户”默认折算为备注 `兼客户:1`，不重复建单位。
- **同时写兼容价格表**：默认不勾。财贸价格主载体是 `T_Jxc_PtypeUnit`，兼容表 `xw_P_PtypePrice` 不是主链路。

点“一键直导（备份→导入→归位→校验）”，工具依次执行：

1. 预检
2. 可选备份
3. 清理上次带 `竞驰导入|` 标记的导入行
4. 写入往来单位
5. 写入商品与单位价格
6. 写入仓库
7. 写入职员、部门
8. 写入期初库存 `IniGoodsStocks`
9. 写入结存库存 `GoodsStocks` / `GoodsStockscost`
10. 写入客户价格追踪 `xw_P_PriceFollow`、最近价格 `RecPrice`
11. 重算子级计数、归位 `UpdateTag=10000`、清 `XW_BaseUpdateTag`
12. 自动执行 32 项校验

日志会显示每类对象的写入行数，例如：

```text
导入完成：单位 5、商品 2、仓库 4、职员 1、部门 1、期初 1、结存 1、单位价格 3、客户价格 0
```

### 重复导入

工具是幂等的：

- 所有导入行备注带 `竞驰导入|原编号:…|原ID:…`
- 再次导入先按标记清理，再重新写入
- 编号基线计算排除这些标记行，重复导入编号不会漂移
- 已实测连续两次一键直导，第二次仍是 32/32、225/225 全通过

- 叶子商品 `nUnit=1` 单位行

## 九、常见问题

### 1. 连接失败：`localhost` / `.` / `(local)`

本机没有默认实例，必须写 `DESKTOP-8P5G8VQ\SQLEXPRESS` 和 `DESKTOP-8P5G8VQ\SQLSERVER`。

### 2. 连接失败：`IM002` / `08001`

工具会自动探测驱动，本机应使用 `ODBC Driver 17 for SQL Server`。若驱动缺失，安装 Microsoft ODBC Driver 17 for SQL Server 后重启工具。

### 3. 预检提示缺表

确认目标库选的是 `财贸测试demo`，不是 `CMDEMO`、`财贸双全普及` 或其他账套。目标库应有 869 张表。

### 4. 附加 MDF 报“拒绝访问”

SQL Server 服务账户没有该文件的读写权限。把 MDF/LDF 移到服务账户可访问的目录，或在 SSMS 中附加后再回到工具“刷新库列表”。不要用改文件权限的方式强行附加生产账套。

### 5. 附加后库名不是原来的账套名

工具优先用 MDF 文件名作为库名；若实例已有同名库，会中止而不是自动加后缀。请先确认是否选错文件，或在 SSMS 中改名后重新附加。

### 6. 32 项校验出现“客户价格追踪 0/0”

这是正常结果。源库 `t_base_price`、`t_base_goodsprice`、`t_Client_Price_goods` 三张专用价格表都是 0 行；31 张含价格/折扣字段的表中只有 6 张有行，且都是商品/往来/库存本身的字段。工具已实现 0005/0006/0007/0008 四类映射，源无数据时目标就是 0 行，不是漏导。

### 7. 库存状况与期初不一致

期初与结存是两套口径：本次源库期初 `t_prime_goodsstock` 为 100，当前结存 `t_base_goodsstock` 为 90。工具按表各写各的，所以 `IniGoodsStocks` 是 100，`GoodsStocks` / `GoodsStockscost` 是 90；这不是漏导。财贸正式开账后，成本流程可能按自身规则重算结存，届时以财贸成本核算结果为准。

### 8. 清缓存提示“未找到”

`F:\GraspServer\CMSQ\Data\BaseInfo\财贸测试demo` 目录当前不存在，说明没有旧缓存，直接重登即可。

### 9. 误导入其他账套

立即停止，使用第三节的备份回滚。不要在没有备份的情况下反复一键直导。

## 十、安全与边界

- 交付文件不保存明文密码；界面密码框输入后仅用于本次连接。
- 导入前建议备份；工具自带 `竞驰导入|` 标记清理，但仍建议保留 `.bak`。
- 不迁移登录用户、权限、会话、程序配置、单据流水、会计凭证。
- 会计科目源 50 行未迁移；目标 `atypecw` 已有 132 个同编号体系科目。如确需迁移科目，请单独评估，不要与本次基础资料直导混在一起。
- 商品条码源 1 行、目标 1 行，`UnitID='0'`，条码 `1234123123124`；工具已写入并保留。
- 客户价格追踪源 0 行，工具能力已实现，本次未写目标。
- MDF/LDF 附加只改变实例上的数据库挂载关系，不修改账套内容；附加前仍建议备份。

## 十一、命令行用法

```powershell
python kpsc_to_cmsg.py --src-server "DESKTOP-8P5G8VQ\SQLEXPRESS" --src-db kspcDefault `
  --dst-server "DESKTOP-8P5G8VQ\SQLSERVER" --dst-db "财贸测试demo" `
  --user sa --password "***" --apply --verify
```

默认写结存库存与客户价格追踪。要关闭：

```powershell
python kpsc_to_cmsg.py ... --apply --no-cur-stock --no-price-follow
```

其他参数：

- `--apply`：执行导入；缺省只预览
- `--verify`：导入后校验
- `--backup <path>`：导入前备份
- `--join`：为“加盟代理:客户”另建单位
- `--compat-price`：同时写兼容价格表

MDF/LDF 附加入口在 GUI 中提供；命令行模式仍需先让账套库处于在线状态。
