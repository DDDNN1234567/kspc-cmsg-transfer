### 1. 三张库存表

| 表 | 目标内容 |
|---|---|

### 2. 财贸读取链路

| 读取 | 结果 |
|---|---|
| `p_jxc_PkuCunList('00000','','',1,'')` | 返回 1 行，`QTY` 合计 100.0 |
| `p_Jxc_GetIniGoodsStocks 'A','00000'` | 读取到期初 1 行 |
| `xw_GetBasicData 'B'` | 5 行（含根） |
| `xw_GetBasicData 'C'` | 4 行（客户，含根） |
| `xw_GetBasicData 'V'` | 2 行（供应商，含根） |
| `xw_GetBasicData 'P'` | 3 行（含根） |
| `xw_GetBasicData 'K'` | 7 行（含根及既有仓库） |
| `xw_GetBasicData 'E'` | 4 行（含既有职员） |
| `xw_GetBasicData 'D'` | 3 行（含根） |

### 3. 口径说明

- 期间 `200601` 来自目标 `T_GBL_SysDataCW.SubName='Period'`，回退 `OpenPeriod`。
- 强制 `Qty * Price = Total`，避免财贸成本层出现“数量、单价、金额三者不一致”。
- 同时写期初与结存，保证迁移后客户端“期初库存”和“库存状况”都能看到 100。
- 财贸正式开账后，成本流程可能按自身规则重算结存；届时以财贸开账结果为准。本报告验证的是“迁移完成时点”的数据完整性。
