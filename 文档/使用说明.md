# 竞驰转财贸直导工具 使用说明（V1.0）

## 一、这个工具做什么

把**竞驰管理通 V8.1** 账套库里的基础资料，按字段对应关系写入**管家婆财贸双全**账套库，并自动校验。

| 导入对象 | 源（竞驰） | 目标（财贸） |
|---|---|---|
| 往来单位（客户/供应商） | `t_base_wldw_inner` | `Btype`（`isclient` 分流） |
| 存货商品（分类+明细+单位+价格） | `t_base_goods_inner` | `ptype` + `T_Jxc_PtypeUnit` |
| 仓库（含子仓） | `t_base_storage_inner` | `Stock` |
| 职员 | `t_base_employees` | `Employee` |
| 部门 | `t_base_department` | `Department` |
| 期初库存 | `t_prime_goodsstock` | `IniGoodsStocks` |
| 结存库存（当前库存） | `t_base_goodsstock` | `GoodsStocks` + `GoodsStockscost` |
| 客户价格追踪 | `t_base_price` | `xw_P_PriceFollow` |
| 最近进价/售价 | 商品 `recprice/recprice1` | `RecPrice` |
| 条码（源有数据时） | `t_base_GoodsBar` | `xw_PtypeBarCode` |

详细逐字段规则见同目录《字段映射表_竞驰到财贸.md》。

---

## 二、运行环境

- Windows 10 / 11
- SQL Server 2008 及以上（源、目标可以是两个不同实例）
- ODBC 驱动：`ODBC Driver 17 for SQL Server`（推荐）、18、13 或 `SQL Server Native Client 11.0`
- 免安装：直接双击 `竞驰转财贸直导工具V1.0.exe`

本机实测：
- 源 `DESKTOP-8P5G8VQ\SQLEXPRESS` / `kspcDefault`（SQL Server 2008 Express SP4）
- 目标 `DESKTOP-8P5G8VQ\SQLSERVER` / `财贸测试demo`（SQL Server 2016）

> 服务器必须写**命名实例**；`localhost` / `.` 在本机没有默认实例，会连不上。

## 三、操作步骤

### 1. 连接与预检

1. 在“源库：竞驰管理通”填服务器、用户名、密码，点“刷新库列表”，选 `kspcDefault`。
2. 在“目标库：管家婆财贸双全”填服务器、用户名、密码，点“刷新库列表”，选 `财贸测试demo`。
3. 点“预检两侧账套结构”，确认源端基础表存在且行数合理、目标端 7 张必需表齐全。
   - 目标缺 `Btype/ptype/Stock/Employee/Department/IniGoodsStocks/T_Jxc_PtypeUnit` 会直接中止，防止写坏非财贸库。

连接参数**默认空白、不预填、不记忆**，每次启动手工填写。

### 2. 一键直导

1. 选择“空单位补为”（默认 `个`）。
2. 保持“导入前备份目标库”勾选。备份路径默认
   `F:\GraspServer\CMSQ\BackUp\竞驰直导前_年月日_时分秒.bak`，
   必须填 SQL Server **服务账户可写**的路径（不要指向用户目录，常见“拒绝访问 错误 5”）。
3. 可选勾选：
   - 导入后清客户端缓存（默认开）
   - 往来关系表另建为客户（默认关，折算为备注）
   - 写结存库存 `GoodsStocks + GoodsStockscost`（**默认开**）
   - 写客户价格追踪 `xw_P_PriceFollow`（**默认开**）
   - 写兼容价格表 `xw_P_PtypePrice`（默认关）
4. 点“一键直导（备份→导入→归位→校验）”，确认提示后等待。
5. 日志页会逐步输出：备份 → 清理旧导入行 → 逐表写入 → 结存库存/价格 → 子级计数重算 → UpdateTag 归位 → 校验 → 清缓存。

### 3. 数据校验

点“执行数据校验”，结果表逐项显示“通过/异常”：

| 检查项 | 判定 |
|---|---|
| 六类对象导入行数 | 与源行数一致 |
| 编号规范 | 无字母、无重复、长度是 5 的倍数 |
| 父级引用 | 无悬空 |
| 子级计数 | `soncount/sonnum` = 实际直接子级数 |
| 商品单位价格表 | 每个叶子商品有 `nUnit=1` |
| 期初库存引用 | 商品/仓库编号都存在 |
| 结存库存行数 | `GoodsStocks`、`GoodsStockscost` 与源结存一致 |
| 库存状况读取 | `p_jxc_PkuCunList` 合计数量 = 源结存 |
| 客户价格追踪 | `xw_P_PriceFollow` 行数 = 源可导行数 |
| 最近价格 | `RecPrice` 行数 = 源有效行数 |
| UpdateTag | 全部 ≥10000 |
| 财贸读取 B/C/V/P/K/E/D | `xw_GetBasicData` 返回行数达标 |

共 32 项。`p_jxc_PkuCunList` 与 `xw_GetBasicData` 都是财贸客户端实际使用的过程，
校验通过即代表“库存状况/基本信息”能取到数。

“重算子级计数 + 归位 UpdateTag”用于修复；正常导入会自动做，无需手工。

### 4. 查看结果

重开财贸客户端登录账套，进入“基本信息”“期初库存”“库存状况”查看。
若界面没变化，点“清客户端缓存”后重登；缓存目录是
`F:\GraspServer\CMSQ\Data\BaseInfo\<账套名>`（不存在时会提示可忽略）。

## 五、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 连接失败，报 `IM002` | 没装可用 ODBC 驱动；装 ODBC Driver 17 for SQL Server |
| 连接失败，报 `08001` 或找不到实例 | 服务器写成了 `localhost`；改命名实例 `机器名\实例名` |
| 备份报“拒绝访问 错误 5” | 备份路径服务账户不可写；改到 SQL Server 的 `BackUp` 目录 |
| 备份报 `WITH COMPRESSION` 不支持 | SQL Server 2008 Express 不支持压缩备份；工具未使用压缩 |
| 目标缺表中止 | 目标库不是财贸账套，或选错库 |
| 客户界面看不到某单位 | 该单位 `isclient=0`（被当供应商）；看备注里的“单位类型” |
| 商品列表空白/树不展开 | 检查编号是否级联、`soncount` 是否为真实子级数；工具已自动重算 |
| 期初库存看不到 | 确认看的是“期初库存”；“库存状况”读 `GoodsStockscost`，本次已写入并可读回 100 |
| 客户价格追踪为空 | 先查源 `t_base_price` 是否有行；本次源库为 0 行，工具已支持四类价格映射 |
| 条码报 245 | `xw_PtypeBarCode.UnitID` 被写成单位名；必须是数字串 `0` |
| 改了库界面无变化 | 清 `Data\BaseInfo\<账套>` 缓存并重登 |

## 六、回滚

导入前的自动备份可直接恢复。示例（在目标实例执行）：

```sql
RESTORE DATABASE [财贸测试demo] FROM DISK = N'F:\GraspServer\CMSQ\BackUp\竞驰直导前_20261106_xxxx.bak'
WITH REPLACE, MOVE N'财贸测试demo' TO N'F:\GraspServer\CMSQ\Data\财贸测试demo.mdf',
     MOVE N'财贸测试demo_log' TO N'F:\GraspServer\CMSQ\Data\财贸测试demo_log.ldf';
```

> 旧版 SQL Server 不要用 `RESTORE VERIFYONLY ... WITH NO_INFOMSGS`，该实例不接受此写法；
> 用 `RESTORE HEADERONLY FROM DISK = N'...'` 校验备份。

也可以只删导入行：五张基础表中 `Comment LIKE '竞驰导入|%'` 的行，以及这些商品对应的
`T_Jxc_PtypeUnit / IniGoodsStocks / GoodsStocks / GoodsStockscost / xw_P_PriceFollow / RecPrice` 行。
工具重复导入时会自动做这一步。

## 八、边界

- 处理**基础资料 + 期初库存 + 结存库存 + 客户价格追踪**，不导单据、权限、程序配置、会计科目（目标已有同编号体系）。
- 会计科目不新建；目标 `atypecw` 已含 1001/1131/1243/1501/2121 等编号。
- 期初写 `IniGoodsStocks`；结存同时写 `GoodsStocks` 与 `GoodsStockscost`（期间取账套当前期间），
  后续开账/过账由财贸成本算法重算。
- 竞驰“往来关系（兼客户/供应商）”在财贸没有对应字段，折算为备注。
