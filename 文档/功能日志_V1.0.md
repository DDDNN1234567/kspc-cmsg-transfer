## 三、界面与交互（对照以往项目要求）

1. **单窗口 + 5 页签**：连接与预检 / 一键直导 / 数据校验 / 字段映射 / 操作日志。
2. **连接参数空白手填、不预填、不记忆**，避免把测试库参数带到生产。
3. **每个动作新建独立连接**，源/目标绝不共用连接，防串库。
4. **busy 锁 + 按钮禁用 + 不定进度条**，耗时任务在后台线程，界面不假死。
5. **线程安全日志**：worker 只入队，主线程 `after` 批量刷新，避免 tkinter 跨线程崩溃。
6. **一键串联**：备份 → 清理旧导入 → 写入 → 重算子级 → UpdateTag 归位 → 校验 → 清缓存。
7. **日志超 3000 行自动裁前 1500 行**，长任务不卡。
8. **失败弹窗 + 状态栏 + 日志复制/导出**，现场可留证。
9. **重复导入安全**：备注标记清理，编号基线排除导入行。

冒烟结果：连接源/目标、预检、预览 28 行、校验 32 行全通过。

## 五、已知限制

1. 源库无客户价格/条码数据，相关目标表为 0 行；工具能力已具备，源有数据即可导入。
2. 结存库存按源当前值写成本层（期间 200601），后续开账/过账由财贸成本算法重算。
3. 会计科目、单据类型、权限、程序配置不迁移（目标自有体系）。
4. 未取得客户端登录界面截图（本机 CU 受账号策略限制）；验收依据为财贸真实读取过程。
