# 竞驰管理通 → 管家婆财贸双全 直导工具 V3.0

按字段对应关系，把竞驰管理通账套库（SQL Server 2008 Express）的基础资料、期初/结存库存、客户价格追踪，直导到管家婆财贸双全账套（SQL Server 2016）。

## V3.0 新增

- **MDF / LDF 直接附加**：连接页可直接选 `.mdf`（可带 `.ldf`）附加到 SQL Server，自动识别已附加库、自动选中库名；只有 MDF 时走 `ATTACH_REBUILD_LOG` 重建日志。
- **数据字典**：遍历源库 104 张表、1626 个字段，逐字段给出源/目标表、类型、转换规则、示例值、状态；输出 MD + CSV。
- **严格逐项核对**：按导入备注中的“原ID”把目标行与源行配对，逐字段比对，当前覆盖 225 项，支持文本、数值容差、布尔、枚举四种模式。
- **工作目录核对**：对照两款软件工作目录的文件清单、字节数、修改时间；核对两侧数据库文件、兼容级别、恢复模式、排序规则。
- **软件完整性检查**：检查目标 11 张关键表、3 个关键存储过程、导入标记行、12 个交付文件（含 exe）。
- **GUI 收口**：连接页增加文件区与“附加两侧文件”，页签重排，主按钮/标题/表格样式统一；窗口最小高度调到 780，避免连接页被截断。
- **线程安全修复**：工作线程不再直接读写 tkinter 变量，UI 更新统一经主线程队列，修复 `RuntimeError: main thread is not in main loop`。
- **结存核对口径修复**：结存期望值改读源 `t_base_goodsstock`（当前库存），不再误用期初表；期初 100 与当前结存 90 各按各的口径核对。

## 快速使用

1. 双击 `竞驰转财贸直导工具V3.0.exe`。
2. “1. 连接 / 账套文件”页填写两侧实例、账号、库；也可直接选 MDF（可带 LDF），点“附加并选中库”或“附加两侧文件”。
3. 点“只读预检两侧账套结构”，确认源表与目标 11 张关键表齐全。
4. “2. 一键直导”页确认勾选“结存库存”“客户价格追踪”，执行一键直导。
5. “3. 数据校验”页执行 32 项校验。
6. “字段映射”页查看字段对应关系。
7. “4. 字典与深度核对”页依次生成字典、严格核对、目录核对、完整性检查。
8. 在财贸客户端清缓存并重登，查看单位、商品、仓库、职员、期初、库存状况。

详细步骤与故障处理见交付包内 `使用说明_V3.0.md`（仓库中位于 `文档/`）。

## 设计口径

- 价格/单位主载体是财贸 `T_Jxc_PtypeUnit`（被大量存储过程引用），兼容表 `xw_P_PtypePrice` / `xw_PtypeUnit` 默认不写。
- 期初落 `IniGoodsStocks`，强制 `Qty * Price = Total`；结存同时写 `GoodsStocks` 与 `GoodsStockscost`，期间取账套当前期间（本次 `200601`）。
- 往来单位按 `Btype.isclient` 分流：竞驰 `type` 0/1/2 → 客户 1，3 → 供应商 0。
- 仓库保留父子层级，子仓编号 = 父编号 + 5 位；本期初挂到子仓。
- 编号纯数字、长度 ≥5 且为 5 的倍数；原编号写入备注，导入行统一带 `竞驰导入|` 标记，重复导入先清理再写入，编号不漂移。
- 客户价格追踪按 0005 进价 / 0006 进货折扣 / 0007 售价 / 0008 销售折扣四类写入 `xw_P_PriceFollow`；最近价格写 `RecPrice`。
- MDF/LDF 附加只改变实例挂载关系，不修改账套内容；已附加库按物理路径识别，不重复 ATTACH。
